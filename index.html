Production-style AWS 3-tier deployment

A three-tier application on AWS with a public load balancer and private application and database tiers, provisioned with Terraform and delivered through Jenkins.

  • AWS
  • Terraform
  • EC2
  • ALB
  • RDS PostgreSQL
  • Docker
  • ECR
  • Jenkins
  • CloudWatch
  • Separate public, private application and database layers inside one VPC.
  • Terraform provisions the VPC, subnets, route tables, security groups, NAT Gateway, ALB, EC2, ECR and PostgreSQL RDS.
  • The application is containerised with Docker and its images are stored in Amazon ECR for deployment on EC2.
  • Jenkins and GitHub automate provisioning, image builds, ECR publishing and deployment.

AWS monitoring and auto-healing platform

Two separate mechanisms for an EC2 instance: CPU alerting through CloudWatch and SNS, and restart of stopped instances through EventBridge and Lambda.

  • AWS
  • CloudWatch
  • EventBridge
  • Lambda
  • SNS
  • EC2
  • Terraform
  • Jenkins
  • Alerting: a CloudWatch alarm watches EC2 CPU utilisation and sends SNS alerts (1-minute evaluation period, set for testing).
  • Recovery: EventBridge detects stopped instances and a Lambda function restarts them.
  • Terraform provisions CloudWatch, EventBridge, Lambda, SNS, IAM and networking; Jenkins automates deployment.
